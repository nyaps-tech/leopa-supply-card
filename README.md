# LEOPA SUPPLY digital business card

Static mobile business card for Blessing Leopa. Includes contact vCard, business-card PDF, print PDF and website QR.

## GitHub Pages

Publish from the main branch, root folder. The public card address is https://nyaps-tech.github.io/leopa-supply-card/

Scanning the QR opens the branded card. Visitors can save the contact or download the designed PDF. Internet is needed to open the page; saved PDFs and contacts work offline.

## Updating

Edit index.html and upload the replacement file. Keep relative asset and download paths. If the site address changes, regenerate the QR and both PDFs before sharing. No build step, external fonts or scripts are required.
